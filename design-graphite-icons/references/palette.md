# 通用配色与材质

## 核心色与角色

| 色彩 | 基准色值 | 跨场景角色 |
| --- | --- | --- |
| 石墨深灰 | `#28292C` | 主要深色、轮廓或深色承托面；替代纯黑 |
| 温和银白 | `#F8F7F3` | 浅色主体、反白图形、亮面或浅色承托面 |
| 暖橙 | `#FF8547` | 少量强调，指向重要部位或信息；不是默认填满的主体色 |

在中性深浅层次上加入少量暖橙，形成低噪声、有温度的视觉语言。保持“深灰与银白建立主次，橙色点缀”的关系，不规定所有图标的固定像素比例。

- 深色底板场景可由石墨占大面积、银白构成主体、橙色小面积强调。
- 浅色环境可把石墨用作图形、银白或透明区域用作留白；不要为了维持“黑为主”强加深色方块。
- 透明背景根据落点选择石墨或银白主体；放到实际背景验证，不假设透明等于白色。
- 单色系统图标只保留所需的一个前景通道，允许没有橙色。网页组件可使用 `currentColor`，在主题端映射合适色值。
- 不增加无关鲜艳色，不把暖橙换成黄色或荧光橙；保留既有且必要的产品语义色与平台颜色约束。

## 可选辅助色

| 色值 | 角色 |
| --- | --- |
| `#3C4046` | 次级深灰或内层承托面 |
| `#D7DCE2` | 轻微银白渐变的阴影端 |
| `#B5BDC7` | 稍重的银灰边缘或层次 |
| `#BDC5CE` | 中性偏冷的浅灰形体 |
| `#A9AFB7`、`#AFB4BA` | 非关键内部细节或辅助层次，不自动视为足够对比的界面线条 |
| `#1B1F25` | 独立大图标确需阴影时的近黑参考，不是纯黑 |

这些是调色板，不要求全部用上，也不绑定某个物件或部件。优先少量颜色；成套图标共享相同角色映射。

## 亮暗主题与对比

- 不把明暗主题简单处理成所有颜色逐项反转；维持清楚的主次与轮廓。
- 不在浅底上把银白当作唯一可识别轮廓，也不在深底上用几乎同色的石墨细线表达关键操作。
- 暖橙基准色在浅底上不一定足够醒目，不能直接假定满足无障碍对比。必要时选择经对比检查的同色系深橙、增加高对比轮廓，或让橙色退为非关键点缀。
- 关键状态同时依靠形状、位置、文字或其他非颜色线索区分。
- 系统单色、tinted、高对比与强制颜色模式优先按各自机制适配；不为保留三个品牌色关闭必要能力。

## 克制的材质

- 小尺寸操作图标优先实色与平面，不使用阴影、渐变或玻璃效果承载含义。
- 独立大尺寸图标确需体积时，可在银白至辅助银灰之间加入平缓渐变，保持单一且一致的光源。
- 深色承托面可有轻微灰阶变化，但不要变成纯黑洞、彩色光晕或纹理背景。
- 需要阴影时使用低强度中性灰，并让方向、偏移和模糊解释真实层次；不把某次设计的阴影强度当作跨平台常量。
- 不把系统会生成的光照、阴影和遮罩预先烘焙进源素材。平台材质能力由相应交付流程处理。

## 颜色检查

1. 检查自绘实色、渐变端点与显式阴影，避免使用 `#000000`、`#000` 或其他等价的纯黑写法。
2. 在实际背景上核对对比度，确保颜色角色而不只是十六进制色值正确。
3. 不把 PNG 透明区域或极低 alpha 边缘的 RGB 量化误判为纯黑图形。
4. 允许操作系统对模板图标、无障碍模式或主题进行颜色转换；检查转换后的可用性，而不是要求所有输出逐像素相同。
